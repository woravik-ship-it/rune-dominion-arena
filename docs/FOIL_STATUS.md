## รอบ 14 (2026-09-25) — ถอด "วงรุ้งเลื่อม" ออก (ไม่เนียน + สีเพี้ยน) เก็บเลื่อมแบบเนียนแทน

**คำติผู้ใช้:** *"รุ้งเลื่อมไม่เอา ไม่เนียน สีเพี้ยนด้วย"*

### สิ่งที่แก้
1. **`FOIL_SPECS.RARE.prism` = false** (กลับไปเป็นแค่ `sweep` — แถบแสงกวาดไล่สี) ตามรอบ 7
2. **`CardFace` กลับมาส่ง `disablePrism={isCanvasVariant(chosenVariant)}`**
   ⇒ ดีไซน์ Canvas (`neon`) **ไม่เรนเดอร์ชั้น `card-foil__prism` (วงรุ้ง) เลยทุกระดับ**
3. ชดเชย "เลื่อม" ที่หายไป (แบบไม่เพี้ยนสี): เพิ่มความสว่าง **แสงกวาดบนตัวภาพ** ที่วาดด้วย Canvas
   (`drawArtSheen`: additive ขาวจางไล่เฉด — บวกแสงเท่านั้น ไม่แตะสีของภาพ)
   `peak 0.22 → 0.30` (`0.13 * band.alpha * spec.alpha`)

### หลักการที่ยึด (จากบทเรียนรอบ 7 + รอบนี้)
- วงรุ้ง `conic-gradient` + `color-dodge`/`screen` ทับภาพ = ต้นเหตุ "แหว่ง/สีเพี้ยน" ที่ผู้ใช้ติซ้ำ
  ⇒ **แสงทุกชั้นที่ใช้จริงเป็น additive (`lighter`) และเป็นเรขาคณิต/เฉดขาวล้วน**
- "เลื่อม" ที่ผู้ใช้รับได้ = `tint` (เฉดสีตามระดับ) + `sweep` (แถบแสงกวาด) + `sparkle` (LEG+)
  + แสงกวาดบนภาพจาก Canvas — ไม่มีชั้นไหนเปลี่ยนสีของภาพ

## รอบ 12 (2026-09-25) — ไม่วนทางเดียวกันหมด · เลิกกระพริบ (เฟดขึ้น/เฟดลงจริง)

**คำสั่งผู้ใช้:** *"ไม่ต้องวนทางเดียวกันหมด วนมาจากทางซ้ายบาง · แล้วเส้นกระพริบมา กระพริบหาย ไม่สวย
เวลาหายให้เฟดลง มาให้เฟดขึ้น หรือเส้นค่อยสั้นหายไป ค่อยยาวโผล่มาก็ได้"*

### 1) "วนมาจากทางซ้ายบาง" — บังคับทิศ/มุมเริ่มให้กระจาย
- เพิ่ม `aOff` (มุมเริ่มต้นของการหมุน) ให้ทุกเส้น: 0 / π/2 / π / 3π/2 (สุ่มต่อใบ)
  → ครึ่งหนึ่ง "เริ่มจากฝั่งซ้าย" อีกครึ่ง "เริ่มจากฝั่งขวา/ด้านหน้า/ด้านหลัง"
- `spin` ของเส้นที่ 2, 4, 6 = **−1 (วนสวนทาง) แบบรับประกัน** (เดิมสุ่มล้วน → อาจออกทางเดียวกันหมด)
- เทสต์ใหม่: `ทิศ/มุมเริ่ม ...` ตรวจว่ามีทั้งเส้นเริ่มซีกซ้าย (x < 210) และซีกขวา (x > 210)

### 2) "กระพริบมา กระพริบหาย" — ต้นเหตุจริง + แก้ที่ราก
| ปัญหา | ต้นเหตุ |
|---|---|
| เส้นวาบโผล่/วับหาย | ชั้น **แสงฟุ้ง (stroke ①)** และ **ไส้ขาว (stroke ③)** ใช้ `alpha` **คงที่** ⇒ พอเส้นเกิด/ดับ ทั้งเส้นสว่างเท่าเดิมทันที = กระพริบ |
| วิธีแก้ | ทุกชั้นใช้ **เฉดที่อ้าง `quad.alpha` จริงของแต่ละช่วง** (`gradOf()`) ⇒ alpha = 0 ที่หัว/ท้ายของช่วงชีวิต ⇒ **เฟดขึ้นตอนเกิด · เฟดลงตอนดับ** ครบทุกชั้น |
| เพิ่มความเนียน | เฉดมี 8 stops · ซองแสง `sin^0.9` ต่อช่วงชีวิต (0→1) · แถบยาวขึ้น/สั้นลงตามเวลา = "ค่อยสั้นหายไป ค่อยยาวโผล่มา" |

- เทสต์ใหม่: `หัวแถบ "เฟดขึ้น–เฟดลง"` — alpha ต่ำสุด < 0.05 (มืดสนิทที่ปลายชีวิต) และสูงสุด > 0.4 (กลางชีวิต)
- เทสต์เดิม `ค่อย ๆ ขึ้น/ค่อย ๆ จาง` ยังผ่าน (ความสว่างไม่กระโดดเกิน 0.2 ใน 50 ms)

### ตรวจแล้ว
- `tsc` 0 error · `jest` **373 ผ่าน / 26 suites** · `next lint` ไม่มี warning ใหม่ · build + restart production
- `inspect:canvas` MYTHIC ✅ 4/4 (ขอบครบ 4 ด้าน · นอกการ์ด ≤ 13) · fps ~53 (median 16.7 ms) บน headless
- `probe-spiral-cycle`: รอยตัดแสงบนแนวนอนสูงสุด 4 รอย · ครอบทั้งการ์ด ≥8/10 แถบ

## รอบ 11 (2026-09-25) — เส้นสุ่มหลายเส้น (หายกลางทางได้) · แสงเนียนไม่เป็นท่อน · คุม 60 fps

**คำสั่งผู้ใช้:** *"เกือบดีแล้ว เพียงแต่ 2 เส้นมันดูเป็นลูปเกินไป เพิ่มเส้นอีก แต่แสดงแบบ Random
ไม่จำเป็นต้องวิ่งสุดการ์ด ทุกเส้น หายไประหว่างทางก็ได้ · เส้นตอนนี้ไม่สมูท ดูแข็ง ๆ เป็นท่อน ๆ
เหมือนรถไฟ มากกว่าแสง"*

### 1) "ดูเป็นลูปเกินไป" → จำนวนรอบผูกกับระยะที่เส้นนั้นเดินจริง
- `turns` ลดจาก 2.0–2.7 → **1.4–1.9 ต่อความสูงการ์ด 1 รอบ**
- เพิ่ม **"ช่วงชีวิต" ต่อเส้น** `w0/w1` (สัดส่วนความสูงการ์ด): เส้นที่ช่วงชีวิต 0.4 ของการ์ด
  จะได้ 0.4×turns ≈ **ไม่ถึง 1 รอบ** ⇒ พาดเฉียง ไม่เป็นวงกลมซ้อน (ลูป)

### 2) "เพิ่มเส้นอีก แบบ Random · หายไประหว่างทางได้"
- จำนวนเส้นตามระดับ: RARE 3 · EPIC 4 · LEGENDARY 5 · MYTHIC 6 (`wisps`)
- **สุ่มแบบ deterministic ต่อการ์ด** (`foilHash(seed~ค่า~i)`) — ใบเดิมได้ผลเดิมเสมอ:
  | ค่า | ช่วงที่สุ่ม |
  |---|---|
  | แกน `centerX` | 0.25–0.75 |
  | รัศมี `spread` | 0.5–0.98 ของค่าฐาน |
  | ทิศ `spin` | ±1 (ครึ่งหนึ่งวนสวนทาง) |
  | ช่วงชีวิต `w0..w1` | ยาว 0.35–0.9 · เริ่มที่ไหนก็ได้ (จบกลางการ์ดได้) |
  | ยาวแถบ `tailClimb` | 0.3–0.7 · ความเร็ว ×0.7–1.6 · กว้าง/สว่าง/เฟส สุ่ม |
- เส้นเอก (i=0) ยังเป็นเส้นยาวเกือบสุดการ์ด เพื่อให้ยังมี "เส้นหลัก" ให้ตาเกาะ

### 3) "ดูแข็ง ๆ เป็นท่อน ๆ เหมือนรถไฟ" → วาดจากเส้นกลางด้วย stroke ปลายมน + ไล่เฉด
| เดิม | ใหม่ |
|---|---|
| รวมช่วงเป็น 6 กลุ่มแล้ว **fill** → alpha กระโดดเป็นขั้น + เหลี่ยมทุกช่วง | สร้าง **`ribbonCenterline()`** (47 จุด) แล้ว **stroke** `lineCap/lineJoin = round` |
| ความหนาเปลี่ยนแบบขั้น (2 ช่วง) | **ซ้อน 4 ความหนา** ที่ทับกัน + เฉด `linearGradient` หัว→หาง (ไม่มีขั้น) |
| 30 ช่วง | 48 ช่วง (`WISP_STEPS`) |

### 4) ประสิทธิภาพยังคงที่
`node /tmp/fps.mjs` → **60.0 fps** (median 16.7 ms) แม้ เพิ่มเป็น 6 เส้น/การ์ด
(ต่อเส้น 6 stroke · เบลอแค่ 1 ครั้ง) · `dpr` จำกัด 1.5 · ขอบการ์ดยังแคชเป็น bitmap

### ไฟล์ที่แก้
`src/lib/card-canvas.ts` (`spiralStrands` สุ่ม + `w0/w1` + `ribbonCenterline`) ·
`src/components/cards/CardAuraCanvas.tsx` (`drawRibbon` ใหม่เป็น stroke ไล่เฉด) ·
`tests/unit/card-canvas.test.ts` (+3 เทสต์: ช่วงชีวิต · สุ่มแต่ deterministic · จำนวนเส้นตามระดับ) ·
`scripts/inspect-card-canvas.mjs` (วัดเส้นขอบ 4 ด้านตรงตำแหน่งจริง)

### ตรวจแล้ว
- `inspect:canvas` MYTHIC ✅ 4/4 · ขอบการ์ดครบ 4 ด้าน (บน 224 · ล่าง 224/255 · ซ้าย 211 · ขวา 224) · นอกการ์ด ≤ 13
- `probe-spiral-cycle`: รอยตัดแสงบนแนวนอนสูงสุด **4 รอย** (หลายเส้นคนละทาง) · จุดวงแหวนเดิมมืด 0/6 เฟรม (ถอดแล้วจริง)

## รอบ 10 (2026-09-25) — วนทั้งการ์ด · หลายเส้นคนละทาง · แก้ "กระตุก" (10 → 59 fps)

**คำสั่งผู้ใช้:** *"ให้วนทั้งการ์ด ไม่ใช่แค่ในภาพ · แล้วเกลียวจะวิ่งเส้นเดียวกันทำไม คนละเส้นสิ
หมุนวนอีกฝั่งก็ได้ บอกให้เช็คตัวอย่าง · แล้วทำไมมันกระตุกมากๆ"*

### 1) วนทั้งการ์ด (ไม่ใช่แค่ในช่องภาพ)
- `spiralGeometry(spec, strand)` เปลี่ยนจากกรอบ `art` → **กรอบการ์ด** (`frame` 8,8,404×584)
  · `yBottom/yTop` = ขอบล่าง/บนของการ์ด · แกน/รัศมีคิดจากความกว้างการ์ด (420) ไม่ใช่ช่องภาพ (372)
- เพิ่ม `clipCard()` (clip ทั้งการ์ดมุมโค้ง) แทน `clipArt()` ในชั้นเกลียว → แสงวิ่งผ่านชื่อ/ข้อความ/สเตตัสได้
  แต่ **ไม่ล้นออกนอกกรอบการ์ด** (ตรวจพิกเซล: นอกการ์ด alpha ≤ 13/255)

### 2) คนละเส้นจริง ๆ (หมุนวนอีกฝั่งได้)
`SpiralStrand` เพิ่ม `centerX` / `spread` / `spin` / `turnScale` → 3 เส้นมี **แกน-รัศมี-ทิศหมุน-จำนวนรอบ** ต่างกัน
| เส้น | แกน (centerX) | รัศมี | ทิศหมุน | รอบ/การปีน | ยาว | สว่าง |
|---|---|---|---|---|---|---|
| 1 | 0.50 (กลาง) | 0.97× | +1 (วนขวา) | 2.7 | 1.0× | 1.0 |
| 2 | 0.36 (ซ้าย) | 0.72× | **−1 วนสวนทาง** | 2.16 | 0.55× | 0.7 |
| 3 | 0.66 (ขวา) | 0.60× | +1 | 3.4 | 0.3× | 0.5 |
ตรวจพิกเซล: นับ "รอยตัดของแสงบนแนวนอน" ได้ถึง **3 รอยพร้อมกัน** ⇒ หลายเส้นคนละทางจริง

### 3) "กระตุกมาก ๆ" — วัดแล้วเจอสาเหตุ + แก้
| ขั้น | วิธีวัด | ก่อน | หลัง |
|---|---|---|---|
| วัด FPS จริง (headless + CDP, rAF delta) | `node /tmp/fps.mjs` | MYTHIC **10 fps** (99 ms/เฟรม) · EPIC 15 fps | **59 fps** (16.7 ms) |
| สาเหตุ | fill ทีละช่วง 44 × 3 รอบ × 3 เส้น + `shadowBlur` ทุกครั้ง (~400 ครั้ง/เฟรม) · stroke กรอบการ์ด 4 ครั้งพร้อม blur ทุกเฟรม | | |
| แก้ 1 | รวมช่วงเป็น path เดียว + เบลอ **ครั้งเดียว/เส้น** (stroke ฟุ้ง) แล้ว fill เป็นกลุ่ม 6 กลุ่ม | | |
| แก้ 2 | **แคชเลเยอร์ขอบการ์ด** เป็น bitmap (`buildFrameLayer`) → `drawImage` ทุกเฟรม | | |
| แก้ 3 | รวมอนุภาค+หางเป็น path เดียว · จำกัด dpr 1.5 · ลด blur ฟุ้ง 16→14 | | |
| บั๊กที่เจอระหว่างแก้ | `clipOutsideArt()` ใช้ `ctx` ปิดทับ → ตอนวาดลง offscreen clip ไปลง canvas หลัก ⇒ ขอบขวา/ล่างหาย + เกลียวถูกตัดเหลือแค่วงขอบ | แก้เป็นรับ `c` เป็นพารามิเตอร์ | |
