# คู่มือผู้เล่น — Rune Dominion Arena (Beta)

> เกมการ์ดแฟนตาซีบนเว็บ เล่นบนมือถือเป็นหลัก
> เหรียญในเกมใช้เล่นเท่านั้น — **ไม่มีเงินจริง ไม่มีการถอน ไม่มีการแลกเปลี่ยนระหว่างผู้เล่น**

---

## 1. เริ่มต้นใน 3 นาที

1. เปิดลิงก์เกมในเบราว์เซอร์มือถือ แล้ว **สมัครสมาชิก**
   - ชื่อผู้ใช้: ภาษาอังกฤษ/ตัวเลข/ขีดล่าง 3–20 ตัวอักษร
   - รหัสผ่าน: อย่างน้อย 8 ตัวอักษร
2. เข้าสู่ระบบ → จะมี **คู่มือเริ่มต้น 4 ขั้น** แนะนำการเล่น (ดูซ้ำได้ที่ ⚙️ ตั้งค่า)
3. ไปที่ **🔮 ค้นหารูน** เพื่อได้การ์ดใบแรก แล้วจัดทีมที่ **🃏 จัดทีม**

---

## 2. ค้นพบการ์ด (หัวใจของเกม)

| หัวข้อ | รายละเอียด |
|---|---|
| วิธีเล่น | แตะรูนบนกระดาน **100×100** จำนวน **8–16 จุด** แล้วกด "ถอดรหัสรูน" |
| กติกาสำคัญ | **ลำดับรูนเดิม → ได้การ์ดใบเดิมเสมอ** (deterministic) |
| พลังค้นหา | **5 ครั้ง/วัน** เติมอัตโนมัติเมื่อขึ้นวันใหม่ (ไม่ต้องกดรับ) · หัวเว็บแสดงตัวเลขจริง ⚡ และ 🪙 ทั้งจอมือถือและจอ Desktop |
| เลื่อนกระดาน | ลาก หรือแตะปุ่มลูกศร ▲▼◀▶ — เลื่อน **วนไม่สิ้นสุด** (สุดขอบด้านหนึ่งแล้วกลับมาอีกด้าน) ไม่มีจุดตัน |
| การ์ดใบแรก | ถ้าเป็นคนแรกที่ค้นพบ จะติดป้าย "ค้นพบครั้งแรก" และเข้าคอลเลกชันเลย |
| รางวัล | ได้การ์ดเข้ากระเป๋าอัตโนมัติ + นับความคืบหน้าภารกิจ "ค้นพบการ์ด" |

**เคล็ดลับ:** ลองจดลำดับรูนที่ได้การ์ดดี ๆ ไว้ — ใส่ลำดับเดิมจะได้การ์ดใบเดิม (แต่การ์ดเดิมจะไม่เพิ่มเข้าคอลเลกชันซ้ำ แต่ยังนับเป็น "การค้นพบ")

## 3. ธาตุและระดับความหายาก

**6 ธาตุ:** เพลิง (EMBERBOUND) · น้ำ (TIDEBORN) · ลม (SKYRIVEN) · ดิน (ROOTFORGED) · แสง (DAWNSWORN) · เงา (VEILMARKED)

**6 ระดับ:** ทั่วไป → ไม่ธรรมดา → หายาก → ตำนาน → ตำนานเลือง → สร้างสรรค์

**สถิติการ์ด:** ATK (โจมตี) · DEF (ป้องกัน) · HP (พลังชีวิต) · SPD (ความเร็ว = ใครได้ก่อน) · Mana Cost (ค่าร่ายสกิล)

**โบนัสพิเศษ:** ทีมที่มี **4 ธาตุขึ้นไป** ได้ **+10% Event Points** ใน Boss Raid

## 4. การต่อสู้

| โหมด | วิธีเข้า | รางวัล |
|---|---|---|
| **ฝึกซ้อม / สู้บอท** | 🃏 จัดทีม → ⚔️ ต่อสู้ → เลือกทีม → สู้กับบอท | นับภารกิจการต่อสู้/ชนะ |
| **อารีน่า 24 ชม.** | ⚔️ อารีน่า → สร้างห้อง (30 Coin) หรือเข้าห้อง (10 Coin) | แชมป์รับ `min(100 + ผู้เข้าร่วม × 5, 500)` Coin · เข้าห้องได้ 20 ครั้ง/วัน |
| **Boss Raid (กิจกรรม)** | 🌙 Events → กด ⚔️ เข้า Boss Raid | Veil Shards + Milestone rewards |

การต่อสู้เป็น **อัตโนมัติ** — ระบบคำนวณทั้งหมดฝั่งเซิร์ฟเวอร์ (ผลตัดสินตามสถิติ + ธาตุ + สกิล) และเก็บ log ให้ดูย้อนหลังได้ทุก action

## 5. จัดทีม

- ทีมมี **5 ใบ** เลือกตำแหน่ง 0–4
- ดู **Team Power** เพื่อเทียบความแข็งของทีม
- ต้องเป็นการ์ดที่คุณเป็นเจ้าของเท่านั้น

## 6. กระเป๋าเงิน (Coin)

- เริ่มด้วย **100 Coin** (โบนัสสมัคร)
- ได้จาก: ภารกิจ, อารีน่า, Milestone ของกิจกรรม
- ใช้จ่าย: เปิดห้องอารีน่า (30), เข้าห้อง (10), ของในร้านค้ากิจกรรม
- ดูรายการทั้งหมดได้ที่ 💰 กระเป๋า — ทุกธุรกรรมมียอดก่อน/หลังให้ตรวจสอบ

## 7. ภารกิจ (Quests)

| ประเภท | งวด |

| รายวัน | รีเซ็ตเที่ยงคืนทุกวัน |

| สะสม (Achievement) | ไม่รีเซ็ต |

## 8. กิจกรรมตามฤดูกาล: "เสียงเรียกจากประตูไร้จันทร์"

ระยะเวลา **14 วัน** + ช่วงเก็บตก 24 ชม.

**วงจรการเล่น:** ทำภารกิจ → ได้ **Veil Shards** → เข้า **Boss Raid** → สะสมคะแนน → รับ **Milestone** → อ่านเนื้อเรื่อง → ซื้อของ

**บอส 4 เฟส** (ตาม HP ที่เหลือ)
| เฟส | HP | ชื่อ |
|---|---|---|
| 1 | 100–76% | ผู้เฝ้ารอยแยก |
| 2 | 75–51% | อัศวินสะท้อนเงา |
| 3 | 50–26% | ม่านไร้จันทร์ |
| 4 | 25–0% | เสียงสะท้อนแห่งรุ่งอรุณ |

**กลไกบอสที่ควรรู้:** Veil Shield (ลดดาเมจ 40% — ธาตุ **แสง** สลายได้) · Moonless Mark (+20% ดาเมจ, **น้ำ** ล้างได้) · Rune Fracture (ทุก 3 เทิร์น) · Ember Break (**ไฟ** ตีทะลุเกราะ) · Rift Hunger (บอสต่ำกว่า 30% จะโหดขึ้น)

**ค่าเข้า Raid:** 10 Veil Shards · **10 ครั้ง/วัน** · แพ้ยังได้ Shards ปลอบใจ 2 ชิ้น

**Milestone ส่วนตัว 7 ระดับ:** 2,000 / 5,000 / 10,000 / 20,000 / 35,000 / 50,000 / 75,000 คะแนน
**เป้าหมายชุมชน:** 1M / 5M / 10M / 25M / 50M ดาเมจรวม (ปลดล็อกบทเนื้อเรื่อง)

## 9. ร้านช่าง (🛠️) + ช่องใส่ Item

**Veil Shards (💠)** คือเงินของร้านช่าง ได้มา **2 ทาง**
| ทาง | รายละเอียด |
|---|---|
| **ขายการ์ดคืนร้าน** | เปิดหน้าการ์ดที่คุณมี → "ขายคืนร้าน" · ได้ตามความหายาก: ทั่วไป **2** · ไม่ธรรมดา **5** · หายาก **12** · ตำนาน **30** · ตำนานเลือง **80** · สร้างสรรค์ **200** ต่อใบ |
| **กิจกรรม** | Boss Raid (ได้คืน 2, ชนะเพิ่ม 5 — ค่าเข้า 10) · ภารกิจกิจกรรม · Milestone ชุมชน |

> การ์ดที่อยู่ในทีมจะขายจนหมดไม่ได้ (ต้องเหลืออย่างน้อย 1 ใบ) — กันทีมพัง

**ใส่ Item ให้การ์ดได้ 3 ช่อง (ช่องละ 1 ชิ้น)** — เปิดหน้าการ์ด → 🛠️ ช่างใส่ Item
| ช่อง | ของที่ใส่ได้ | ตัวอย่าง |
|---|---|---|
| **โจมตี** | อาวุธ/ของเพิ่มพลังโจมตี | หินลับคม (+6 ATK) · ดาบไร้จันทร์ (+32 ATK +4 SPD) |
| **ป้องกัน** | โล่/ของเพิ่มป้องกันและ HP | โล่ไม้โอ๊ก (+6 DEF +10 HP) · โล่ผู้เฝ้าม่าน (+55 DEF +95 HP) |
| **สนับสนุน** | เครื่องราง/น้ำยา เพิ่มความเร็วและฟื้นพลัง | เครื่องรางว่องไว (+5 SPD +4 HP) · ตราเซลิน (+40 SPD +40 ATK) |

- **Status ของ Item บวกเข้าสถานะการ์ดจริง** — ใช้ตอนต่อสู้/คิดพลังทีม (ไม่ใช่แค่ตัวเลขโชว์)
- ได้ Item มา 2 ทาง: **ซื้อด้วย Veil Shards** (ของพื้นฐาน) หรือ **คราฟต์ด้วย Veil Shards + ฝุ่นเวท** (ของแรงกว่า — ฝุ่นเวทได้จากกิจกรรม)
- ของซ้ำสามารถใส่ได้หลายการ์ด (1 ชิ้น = ใส่ได้ครั้งเดียว) — อยากใส่หลายใบให้ซื้อ/คราฟต์เพิ่ม

## 10. กระเป๋า (🎒) — เงิน + ไอเทม + ของสะสม

เปิดเมนู 🎒 **กระเป๋า** จะเห็นครบในหน้าเดียว

| ส่วน | มีอะไร |
|---|---|
| **💰 เงินในกระเป๋า** | 🪙 Coin (กดไปหน้า Coin) · 💠 Veil Shards (กดไปร้านช่าง) · ✨ ฝุ่นเวท (ใช้คราฟต์ Item) |
| **🛠️ ไอเทมช่าง** | Item ที่มีอยู่ แยกตามช่อง (โจมตี/ป้องกัน/สนับสนุน) พร้อม Status ที่เพิ่มให้การ์ด + บอกว่า**ใส่อยู่กี่ชิ้น** — กด "ไปหน้าการ์ด" เพื่อใส่ |
| **🎁 ของสะสมจากกิจกรรม** | ของที่ได้จากกิจกรรม แยก 5 ประเภท: การ์ดพิเศษ · เครื่องประดับ · ฉายา · วัตถุดิบ · บทเนื้อเรื่อง — พร้อมบอก **ที่มา** ของทุกชิ้น |

## 11. โปรไฟล์ + อวตาร (👤)

เปิดเมนู 👤 **โปรไฟล์** เพื่อดูข้อมูลจริงของบัญชีคุณ

- **ตัวตน:** ชื่อที่แสดง · @username · บทบาท (ผู้เล่น/แอดมิน) · วันที่เข้าร่วม
- **ยอดเงินและพลัง:** Coin · Veil Shards · ฝุ่นเวท · พลังค้นหา
- **สถิติการเล่น:** ศึกที่เล่น / ชนะ / แพ้ / อัตราชนะ · ชนิดการ์ด · การ์ดทั้งหมด · การ์ดที่ปักหมุด · ทีม · ภารกิจที่รับรางวัล · ไอเทมในคลัง / ที่ใส่
- **กิจกรรมล่าสุด:** คะแนนกิจกรรม · ดาเมจรวม · Veil Shards ที่ได้/ใช้ในกิจกรรม

**อวตาร — เลือกได้ 2 แบบ (แสดงบนหัวเว็บทุกหน้า)**
| แบบ | วิธีทำ |
|---|---|
| 😀 **เลือกอิโมจิ** | กดแท็บ "เลือกอิโมจิ" แล้วแตะอิโมจิที่ชอบ (32 แบบ) — บันทึกทันที |
| 🎨 **วาดเอง 6×6** | กดแท็บ "วาดเอง 6×6" → เลือกสีจากพาเลตต์ 8 สี → แตะช่องเพื่อระบาย (มี 🧽 ยางลบ + 🧼 ล้างช่องทั้งหมด) → กด 💾 **บันทึกภาพวาด** |

> ปุ่ม ♻️ ล้างอวตาร = กลับไปใช้ไอคอน 👤 · อวตารใหม่จะขึ้นบนหัวเว็บ**ทันที** ไม่ต้องรีเฟรช

## 12. ตารางจัดอันดับ (🏆)

เปิดเมนู 🏆 **จัดอันดับ** เพื่อเทียบกับผู้เล่นทั้งเซิร์ฟเวอร์ — ดูได้ทุกคน (ไม่ต้องล็อกอิน)

| แท็บ | จัดอันดับจาก |
|---|---|
| ⚔️ **พลังทีม** | พลังรวมทีมที่ดีที่สุดของคุณ (ATK+DEF+HP+SPD ของการ์ด 5 ใบ **บวก Item ที่ใส่**) |
| 🃏 **คะแนนสะสมการ์ด** | rarity × จำนวนใบ (ทั่วไป ×1 · ไม่ธรรมดา ×2 · หายาก ×4 · ตำนาน ×8 · ตำนานเลือง ×16 · สร้างสรรค์ ×32) |
| 🏆 **ชนะศึก** | จำนวนครั้งที่ชนะ (+ จำนวนศึกที่ลง) |
| 🌙 **คะแนนกิจกรรม** | คะแนนรวมจากกิจกรรม (+ ดาเมจรวม) |
| 🪙 **Coin** | ยอด Coin ในกระเป๋า |

- แสดง **50 อันดับแรก** พร้อมเหรียญ 🥇🥈🥉 และอวตารของผู้เล่น
- ถ้าเท่ากันจะได้ **อันดับเดียวกัน** (เช่น 1, 2, 2, 4)
- ล็อกอินอยู่: มีบรรทัด **"อันดับของคุณ: #N จากทั้งหมด"** และแถวของคุณถูกไฮไลต์เสมอ

## 13. ตั้งค่าและช่วยเหลือ (⚙️)

| ตัวเลือก | ผล |
|---|---|
| เสียงเอฟเฟกต์ (SFX) | เปิด/ปิดเสียงกดปุ่ม เปิดการ์ด ต่อสู้ (เสียงดาบ ดาบกระทบดาบ ปล่อยสกอล โล่ เผาไหม้ ฟื้นพลัง ล้ม) — กลุ่มเสียงต่อสู้ปรับให้ดังและมีมิติเป็นพิเศษ |
| เพลงประกอบ | เพลงธีมหลัก (เปิดเป็นค่าเริ่มต้น — จะเริ่มเล่นหลัง**แตะหน้าจอครั้งแรก** เพราะเบราว์เซอร์บล็อกเสียงอัตโนมัติ) |
| เสียงบรรยากาศ | เสียงพื้นหลังของแต่ละโซน |
| **ลดเอฟเฟกต์รุนแรง** | เหมาะกับผู้ที่ไวต่อเสียง — ลดเสียงซ้อนและความดังลงครึ่งหนึ่ง |
| ระดับเสียง | ปรับ 0–100% |
| เปิดคู่มือเริ่มต้นอีกครั้ง | ดู onboarding ซ้ำ |

> หมายเหตุ: เบราว์เซอร์มือถือบล็อกเสียงอัตโนมัติ — **แตะหน้าจอหนึ่งครั้ง** เพื่อเปิดระบบเสียง
> หมายเหตุ 2: **ระหว่างต่อสู้ เพลงจะลดลงชั่วคราวในจังหวะที่เสียงดาบ/เวทกระแทก** แล้วกลับมาดังเท่าเดิมทันที (เทคนิคเดียวกับงานมิกซ์เพลง) เพื่อให้ได้ยินเสียงต่อสู้ชัดขึ้นโดยไม่ต้องเร่งวอลุ่ม

## 14. กติกาที่ควรรู้ (กันปัญหายอดฮิต)

- **พลังงานค้นหา** 5/วัน — ใช้หมดแล้วรอข้ามวัน (หรือให้แอดมินเติม)
- **การค้นพบซ้ำ** ได้การ์ดใบเดิม แต่ไม่เพิ่มเข้าคอลเลกชันซ้ำ
- **ยิงคำขอถี่เกินไป** ระบบจะตอบ "คำขอถี่เกินไป" — รอสักครู่แล้วลองใหม่
- **เข้าห้องอารีน่า** ได้ 20 ครั้ง/วัน และ **Raid** 10 ครั้ง/วัน
- **Item 1 ชิ้นใส่ได้ครั้งเดียว** — ของซ้ำต้องซื้อ/คราฟต์เพิ่มจึงจะใส่การ์ดใบอื่นได้
- **การ์ดที่อยู่ในทีมขายจนหมดไม่ได้** — ต้องเหลืออย่างน้อย 1 ใบ (เอาออกจากทีมก่อน)
- **รับรางวัลซ้ำ** ไม่ได้ — ถ้าระบบบอก "รับไปแล้ว" แปลว่ารับสำเร็จไปก่อนหน้า
- ถ้าเจอหน้าจอ error ให้กด **"ลองใหม่"** แล้วแจ้ง **รหัสอ้างอิง (digest)** ที่แสดงบนหน้าจอให้ทีมงาน

|---|---|---|
| 🔮 | ค้นหารูน | ถอดรหัสรูน 8–16 จุด |
| 🃏 | คอลเลกชัน / จัดทีม | ดูการ์ดและจัดทีม 5 ใบ |
| ⚔️ | ต่อสู้ / อารีน่า | สู้บอท หรือแข่งห้อง 24 ชม. |
| 📜 | ภารกิจ | บอร์ดภารกิจ + รับรางวัล |
| 🌙 | Events | กิจกรรมตามฤดูกาล + Boss Raid |
| 🛠️ | ร้านช่าง | ซื้อ/คราฟต์ Item (💠 Veil Shards + ✨ ฝุ่นเวท) |
| 🎒 | กระเป๋า | เงิน (Coin/Veil Shards/ฝุ่นเวท) + ไอเทมช่าง + ของสะสมจากกิจกรรม |
| 👤 | โปรไฟล์ | ข้อมูลผู้เล่น · สถิติ · อวตาร (อิโมจิ หรือวาดเอง 6×6) |
| 🏆 | จัดอันดับ | ตาราง Ranking ผู้เล่น 5 หมวด + อันดับของคุณ |
| 💰 | กระเป๋า Coin | Coin และประวัติธุรกรรม |
| 💠 | (ในหัวเว็บ) | ยอด Veil Shards — กดเพื่อเข้าร้านช่าง |
| ⚙️ | ตั้งค่า | เสียง/ช่วยเหลือ/เกี่ยวกับ |
