## 2. วิธีถ่าย (Chrome DevTools)

1. เปิด Chrome → F12 → กด **Toggle device toolbar** (⌘⇧M / Ctrl+Shift+M)
2. เลือก **iPhone 14 Pro** (390×844, DPR 3) — ให้ได้ภาพคมระดับ store
3. ล็อกอินบัญชีทดสอบที่มีข้อมูลน่าสนใจ (การ์ด ≥6 ใบ, ทีมครบ, มี Veil Shards)
4. กด **Capture screenshot** (ไอคอนกล้องมุมขวาบน) หรือ `Capture full size screenshot` สำหรับภาพยาว
5. บันทึกเป็น `public/marketing/01-home.png` … ตามตารางข้างบน

> เคล็ดลับ: ปิดแถบ debug (Network console) ก่อนถ่าย และตั้งธีมเป็นค่าเริ่มต้น
